## Curriculum Vitae

Проект был выполнен в рамках Т-интенсива по JavaScript от ТБанка (лето 2025 г.)

**Curriculum Vitae** - статический сайт с редактируемым резюме, двумя вариантами макета и экспортом в PDF.

Проект подготовлен под требования из [`statement.md`](statement.md):

- вёрстка резюме по шаблону из Figma;
- редактирование содержимого прямо в интерфейсе через `edit.html`;
- сохранение данных пользователя в `localStorage`, чтобы изменения не терялись после обновления страницы;
- кнопка **Save as PDF** для сохранения текущей версии резюме;
- CSS-анимации интерактивных элементов;
- эффект "Material Wave" для кнопок и управляющих элементов;
- переключение между двумя версиями макета: **v1** и **v2**;
- адаптация под разные размеры экрана.

### Структура проекта

```text
.
├── css/
├── data/
├── js/
├── edit.html — редактирование данных
├── index.html — просмотр резюме
└── print.html — экспорт в PDF
```

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- `localStorage` для сохранения пользовательских данных

### Как запустить локально

Проект не требует сборки и сторонних зависимостей.

1. Склонируйте репозиторий.
2. Откройте проект в VS Code.
3. Запустите `index.html` через **Live Server** или любой другой статический локальный сервер.

---

### Примечание

Экспорт в PDF использует встроенный печатный сценарий браузера и сохраняет текущую версию резюме с активным layout-переключателем.
